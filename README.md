# ECHO — عالمك الرقمي الشخصي

تطبيق أندرويد (Flutter) يحوّل ذكرياتك وأفكارك وإنجازاتك إلى **عالم تفاعلي**: كل تصنيف جزيرة، وكل ذكرى نجمة يمكنك لمسها وفتحها.
يعمل بالكامل **محليًا على الهاتف**: بلا خادم، ولا حساب، ولا اشتراك، ولا صلاحيات خاصة، ولا يُرسل أي شيء من بياناتك إلى أي جهة.

## الميزات

- **العالم**: مشهد تفاعلي مرسوم بـ `CustomPainter` (ثنائي الأبعاد وليس ثلاثي الأبعاد حقيقيًا): تكبير بالقرص، تحريك عند التكبير، لمس النجمة لفتح الذكرى، مع وضع «أداء خفيف» بلا حركة.
- **الذكريات**: عنوان، نص، تاريخ ووقت، تصنيف، وسوم، لون، أيقونة، أهمية (1–5)، وصور (حتى 10) تُحفظ داخل مجلد التطبيق الخاص.
- **استكشاف**: بحث فوري، تصفية بالتصنيف والتاريخ، وفرز (الأحدث/الأقدم/الأهم).
- **تصنيفات**: سبعة تصنيفات جاهزة (حياتي، أفكاري، إنجازاتي، أهدافي، لحظات مهمة، يومياتي، أفكار مستقبلية) مع إضافة وتعديل وحذف. عند حذف تصنيف تُنقل ذكرياته إلى «حياتي».
- **إحصائيات**: أرقام محسوبة من بياناتك الفعلية فقط.
- **الإعدادات**: مظهر داكن/فاتح/النظام، وضع الأداء الخفيف، تصدير واستيراد نسخة احتياطية (مع التحقق من الملف قبل أي تغيير)، حذف كل البيانات.
- واجهة عربية RTL كاملة، وحالات فارغة ورسائل نجاح/خطأ مفهومة.

## هيكل المشروع

```
lib/
  main.dart, app.dart          نقطة الدخول والتطبيق (Provider + MaterialApp)
  core/                        الثوابت، الأيقونات، التنسيق، السمة
  data/                        النماذج، SQLite، المستودع، تخزين الصور
  logic/                       البحث/الفرز، الإحصائيات (دوال نقية قابلة للاختبار)
  state/                       MemoryController, SettingsController
  services/                    النسخ الاحتياطي والاستعادة
  navigation/                  الشريط السفلي والانتقالات
  features/                    home, memory, explore, stats, settings
  widgets/                     بطاقة الذكرى، الخلفية، الحالات الفارغة
test/                          اختبارات الوحدات وSQLite والنسخ الاحتياطي والواجهة
android/                       إعدادات Android (com.echo.memory)
.github/workflows/android-build.yml
```

## التشغيل محليًا (يتطلب Flutter 3.27.4 وAndroid SDK)

```bash
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter run                      # على هاتف أو محاكي
flutter build apk --release      # الناتج: build/app/outputs/flutter-apk/app-release.apk
```

> إصدار Flutter المثبّت في المشروع هو **3.27.4**. الكود يستخدم `Color.withValues` المتوفر من 3.27 فصاعدًا.

## بناء APK بدون تثبيت أي شيء (GitHub Actions)

1. أنشئ مستودعًا جديدًا على GitHub (فارغًا، بفرع رئيسي اسمه `main`).
2. ارفع محتويات هذا المجلد إلى المستودع:
   - من المتصفح: **Add file → Upload files** ثم اسحب كل الملفات والمجلدات (تأكد من رفع المجلد المخفي `.github`).
   - أو من الطرفية:
     ```bash
     git init
     git add .
     git commit -m "ECHO initial commit"
     git branch -M main
     git remote add origin https://github.com/<USER>/<REPO>.git
     git push -u origin main
     ```
3. سيعمل الـ Workflow تلقائيًا عند الدفع إلى `main`، ويمكنك تشغيله يدويًا من **Actions → Android Build → Run workflow**.
4. بعد نجاحه افتح تشغيل الـ Workflow، وفي أسفل الصفحة قسم **Artifacts** ستجد **`echo-release-apk`**. نزّله وفك الضغط وثبّت `app-release.apk` على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

مراحل الـ Workflow: إعداد Java 17 وFlutter 3.27.4 ← `flutter pub get` ← تنسيق الكود ← `flutter analyze` ← `flutter test` ← `flutter build apk --release` ← رفع APK. أي مرحلة تفشل توقف ما بعدها ولا يُرفع APK.

## ملاحظات مهمة

- **التوقيع**: نسخة Release موقّعة بمفتاح debug لتكون قابلة للتثبيت مباشرة. لنشر التطبيق في متجر أنشئ keystore حقيقيًا.
- **ملف `pubspec.lock`** غير مرفق (لم يكن Flutter متاحًا عند إنشاء المشروع). يُنشأ عند أول `flutter pub get`؛ يُفضّل رفعه إلى المستودع بعد ذلك لتثبيت إصدارات الحزم.
- **النسخ الاحتياطي** ملف JSON يتضمن الصور مشفّرة base64، فقد يكبر حجمه مع كثرة الصور. الاستيراد **يستبدل** البيانات الحالية بعد تأكيدك.
- تنفيذ `android:allowBackup="false"` يعني أن نسخ أندرويد التلقائي (Google Backup) معطّل، فاستخدم تصدير النسخة الاحتياطية من الإعدادات للحفاظ على بياناتك.
